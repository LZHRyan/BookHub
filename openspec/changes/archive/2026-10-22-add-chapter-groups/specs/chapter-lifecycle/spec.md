# Spec Delta

## MODIFIED Requirements

### Requirement: 章节排序调整

系统 SHALL 允许管理员通过上移、下移或直接指定顺序调整章节在同级目录中的位置。一次排序调整 MUST 以单个原子操作重写该父级（分卷内或根层）的顺序，调整后 MUST NOT 出现顺序重复或顺序缺号，刷新页面后顺序保持不变。MUST NOT 因为调整某个分卷内的顺序而改变其它分卷或根层的相对顺序。

#### Scenario: 上移立即生效

- **WHEN** 管理员把分卷内第三位的章节上移一位
- **THEN** 该章节变为该分卷内的第二位，原第二位章节变为第三位
- **AND** 根层与其它分卷的顺序不变

#### Scenario: 调整后顺序持久一致

- **WHEN** 管理员完成一次排序调整后重新加载目录页
- **THEN** 章节顺序与调整结果一致

#### Scenario: 调整中失败不改动顺序

- **WHEN** 一次排序请求携带了不属于该 Book 的章节标识
- **THEN** 系统返回 4xx 状态码
- **AND** 该 Book 下所有章节的顺序保持调整前的状态

## ADDED Requirements

### Requirement: 删除分卷 MUST 先清空子章节

删除命令对分卷的语义 MUST 与章节软删除区分：仍有子章节的分卷 MUST 拒绝删除并给出子章节数量；空分卷删除后进入回收站，恢复后回到原位置。

#### Scenario: 非空分卷删除被拒绝

- **WHEN** 管理员对含子章节的分卷发起删除
- **THEN** 返回 4xx 并提示先移出或删除这些章节
- **AND** 分卷状态保持不变

#### Scenario: 空分卷删除可恢复

- **WHEN** 空分卷被删除后从回收站恢复
- **THEN** 该分卷重新出现在目录的原位置
- **AND** 可以继续往其中添加章节
