# 访客阅读侧说明

面向「只看文档、不登录」的同事。所有 URL、可见性与 404 行为都取自 `app/web/public.py`、`app/templates/*.html`、`app/static/style.css`。

---

## 1. URL 规则

目录是**两级**：Book → 章 → 节。一节 = 一份文件（`.md` / `.html`），正文与版本都在节上。

| 路径 | 页面 | 参数 | 数据范围 |
| --- | --- | --- | --- |
| `/` | 首页：Book 卡片列表 | `?page=N`（每页 12 个，`page≥1`） | 仅 `visibility=public` 且未删除的 Book |
| `/b/{book_slug}` | Book 目录页（章 → 节两级） | 无 | 该 Book 下**已发布**的章及其未删除的节 |
| `/b/{book_slug}/{chapter_slug}` | 章页，**双形态**（见下） | 无 | 单章；草稿/已删除 → 404 |
| `/b/{book_slug}/{chapter_slug}/{section_slug}` | 节阅读页（唯一正文出口） | 无 | 单节；草稿章下的节 / 已删除 → 404 |
| `/b/{book_slug}/{chapter_slug}/{section_slug}/raw` | 原始 HTML 文档（新标签页） | 无 | 单节原文，不做净化；仅 `html` 格式的节有，草稿/已删除 → 404 |
| `/search` | 搜索结果页 | `?q=关键词&book={book_slug}&page=N`（每页 20 条） | 已发布章下、Book 为 public 的节 |
| `/static/*` | 静态资源 | — | `style.css` / `app.js` / `pygments.css` |
| `/healthz`、`/readyz` | 探针 | — | 见 [deploy.md](deploy.md) |

**章页的双形态**（`app/web/public.py` 的 `chapter_detail`）：

| 章里的节数 | `/b/{book}/{chapter}` 的行为 |
| --- | --- |
| 1 节 | 直接渲染这一节的正文（等价于节页；**存量链接因此继续可用**） |
| ≥2 节 | 渲染该章的**节索引页**（`chapter_index.html`），链接到每个节页 |
| 0 节 | 200 + 空状态提示（「这一章还没有节」） |

**两代地址对照**：

| 场景 | 一代（分卷时代 / 迁移后的旧链接） | 二代（章 → 节） |
| --- | --- | --- |
| 单节章的正文 | `/b/ops/deploy` | `/b/ops/deploy`（直出）或 `/b/ops/deploy/<节 slug>` |
| 多节章的落地页 | 不存在（原来一章就是一篇） | `/b/ops/deploy`（节索引） |
| 具体某一节 | 不存在 | `/b/ops/deploy/architecture` |
| HTML 节原文 | `/b/ops/page/raw` | `/b/ops/page/<节 slug>/raw`（`/raw` 下沉到节） |

**兼容**：`/b/{book}/{chapter}` 在单节章上直接渲染那唯一一节（正文与节页一致），所以旧地址照旧可用。此时「复制链接」与 `og:url` 用章地址，避免同一篇内容有两个分享地址；多节章的章页是节索引，分享节时用节地址。

- `book_slug` / `chapter_slug` / `section_slug` 都是 slug，**不是数字 id**。纯中文标题会得到 `book-3f9a1c` / `chapter-8c21f0` / `section-3ab1c9` 这类回退 slug（见 [content-model.md](content-model.md)）。章在 Book 内唯一，节在章内唯一。
- `q` 超过 500 字符时返回 400「查询词不能超过 500 个字符」。
- `book` 参数传入不存在的 slug 时，页面不报 404，而是返回空结果（并在顶部提示限定 Book 失效）。

## 2. 可见性与 404 语义

### 2.1 Book 的可见性

| 值 | 首页 | Book 页 | 搜索 | 直链 | API 列表 | API 详情 |
| --- | --- | --- | --- | --- | --- | --- |
| `public` | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| `unlisted` | ❌ | ✅ | ❌ | ✅ | ❌ | ✅（按 slug/id 取仍可） |

`unlisted` 的定位是「**不对外宣传，但知道链接的人可以读**」——适合内部运维笔记、临时方案。注意它**不是权限控制**：只要拿到 slug，任何人都能读，也能通过 `/api/v1/books/{slug}` 取到内容（该端点不按 visibility 过滤）。真正的"不给看"只有两种做法：放草稿，或删掉。

### 2.2 一律 404 的情况

发布状态只在**章级**：章 `published` → 它下面所有节对外可见；章 `draft` → 所有节 404（不会出现"半章可见"）。以下情况访客页面返回 **404**：

- 章是**草稿**（`status=draft`）→ 章页与它下面每个节页都 404；
- 章或节**已删除**（软删除）；
- 所属 Book **已删除**；
- slug 根本不存在。

**草稿对访客与登录用户都 404**：`find_chapter()` / `find_section()` 只按状态判断。要以访客视角检查草稿内容，用管理端的「访客视角预览」（章编辑器顶部链接，或直接访问 `/admin/books/{book_id}/chapters/{chapter_id}/preview`）：预览不会改变章状态，也不会让访客看到。

已发布的章撤回为草稿后，之前分享出去的章页与节页链接会立刻 404。

## 3. 面包屑与章节导航

**面包屑**：

```text
站点名 / Book 标题 / 章标题 / 节标题     ← 节页
站点名 / Book 标题 / 章标题             ← 章索引页
站点名 / Book 标题                      ← Book 页
```

站点名取自「站点设置」（未自定义时用 `SITE_NAME`）。

**上一篇 / 下一篇**只在节页底部出现，按「章顺序 → 章内节顺序」拍平后的**已发布节序列**跳转：跨章也会接上；第一节没有"上一篇"，最后一节没有"下一篇"。草稿章不占位置。

节页顶部还有一行元信息：`章标题 N/M 节 · 共 X 字 · vN`；底部：`更新于 YYYY-MM-DD HH:MM · 版本 vN · API`（`API` 指向该节的 `/api/v1` JSON，带 `?section=`），登录状态下额外显示「编辑」。

**分享**：节页与 Book 页都有「复制链接」按钮，复制的是**绝对地址**（含反代前缀），可以直接贴到 IM 或邮件里。页面同时输出 Open Graph 标签（og:title / og:description / og:url，Book 有封面时还有 og:image），企业微信、钉钉、Slack 等会渲染成带标题与摘要的卡片。

## 4. 页内目录与锚点

- 节里的每个标题（`h1`–`h6`）都会得到锚点 id，由标题文本生成：保留字母、数字、**中文**，其余字符转 `-`，重复时追加 `-2`、`-3`。
- 左侧「本页目录」列出这一节的所有标题，按层级加 `lvl-N` 缩进；滚动时高亮当前所在小节（`app.js` 用 `getBoundingClientRect().top <= 120` 判断）。宽度 ≤1024px 时左侧栏隐藏，改由正文上方的「本页目录（N 节）」折叠块承担同样内容。
- 直接分享锚点链接即可：`/b/dev-handbook/deploy/architecture#回滚流程`（中文锚点会被浏览器 URL 编码）。
- HTML 节如果自己写了 `id`，会优先保留；同一节内 id 重复时才重新生成。
- 目录为空（正文没有任何标题）时左侧栏不渲染，正文占满整行。

## 5. HTML 文档的「原始排版」

格式是**节级**的：同一章里可以既有 Markdown 节也有 HTML 节（Book 的文档类型只是新建节时的默认值）。HTML 节默认按「原始文档」提供；管理员可在 Book 设置里改成站内渲染：

| 阅读方式 | 节页 | 说明 |
| --- | --- | --- |
| `document`（原始文档，默认） | 节页仍可看，但 Book 目录里的 HTML 节链接直接在新标签页打开 `/b/{book}/{chapter}/{section}/raw` | 原样输出上传的 HTML：文档自己的 CSS、JS、base64 图片、内置导航全部生效 |
| `inline`（站内安全渲染，需手工选择） | 节页内联渲染 | 先按白名单净化：`<script>`、内联事件、自定义 `<style>`、inline `style`、`data:` 图片全部被移除，只留结构与文本；用站点自己的排版和左栏目录 |

`/raw` 端点的安全边界（`app/web/public.py` 的 `RAW_DOCUMENT_CSP`）：

- 响应头带 `Content-Security-Policy: sandbox allow-scripts allow-popups ...`，**故意不含 `allow-same-origin`**：浏览器把这份文档当成唯一源，文档里的脚本照常执行，但读不到本站 Cookie / localStorage，也拿不到同源接口的响应；
- 另带 `Referrer-Policy: no-referrer`、`X-Robots-Tag: noindex, nofollow`、`Cache-Control: no-store`；
- 资源加载放开到任意来源（方便文档引用 CDN），但**相对路径资源仍然加载不到**（本站没有附件/静态资源上传），请用 base64 内嵌或绝对 https URL；混合内容（`http://` 资源）会被浏览器拦掉。

另外：左侧「本页目录」来自站点按 `h1`–`h6` 生成的锚点；原始文档模式下，导航由上传的文档自己提供，站点目录只在节页兜底显示。

## 6. 打印

`style.css` 里有 `@media print` 规则，打印/导出 PDF 时：

- 隐藏顶栏、页脚、左侧目录、上一篇/下一篇、面包屑；
- 正文卡片去掉边框与阴影，背景转白、文字转黑、链接去色；
- 阅读区变成单栏（宽屏双栏布局塌缩）。

也就是说 Ctrl+P 出来的就是**纯正文**。代码块样式由 `pygments.css` 提供，打印时同样保留配色（黑底代码块在部分浏览器"打印背景图形"关闭时会变白底黑字，属浏览器行为）。

## 7. 搜索页

- 顶部搜索框（`name=q`）在任意页面都能用，回车即跳 `/search?q=...`。
- 结果每条展示：节标题、`Book 标题 / 章标题`、更新日期、命中片段（命中词用 `<mark>` 高亮），点开落到节页。
- 单字查询（如只搜「库」）会退化成模糊匹配，结果卡片上会有一个 **「单字模糊匹配」** 标记，表示精确度较低。原理见 [search.md](search.md)。
- 结果分页 20 条/页；首页与 Book 页是 12 个 Book/页，两者不同。

## 8. 站点设置在哪里改

三处文案存在数据库（`site_settings` 表），**优先级高于环境变量**：

| 文案 | 后台位置 | 环境变量默认值 |
| --- | --- | --- |
| 站点名（顶栏、页脚、面包屑首项、`<title>`） | `/admin/settings` 的 `site_name` | `SITE_NAME` |
| 页脚文字 | 同上 `site_footer` | `SITE_FOOTER` |
| 首页说明 | 同上 `home_intro` | `HOME_INTRO` |

- 只有 `admin` 角色能进 `/admin/settings` 保存；保存后立刻生效（每次请求都从库里读），不需要重启。
- 站点名不能为空（留空会提示「站点名不能为空」）。
- 首页说明支持 HTML 并**原样输出**（模板里是 `| safe`），写富文本横幅可以，但请注意这等于允许 `admin` 往首页注入任意 HTML——只给可信的人管理员权限。
- 想恢复环境变量里的默认值，需要删掉 `site_settings` 里对应的行（目前后台没有"恢复默认"按钮）。

## 9. 已知限制

| 限制 | 说明 |
| --- | --- |
| 预览需登录 | 草稿只能通过管理端 `/admin/.../preview` 预览（需登录），没有公开的预览令牌链接 |
| 无评论/无点赞 | 只读系统，没有互动功能 |
| 无图片上传 | 正文里的图片只能引用外部 URL（`img` 标签的 `src` 允许 `http/https`），没有附件/对象存储 |
| 无全文高亮跳转 | 搜索结果只给片段，不定位到节内的具体位置 |
| 时间是 UTC | 页面上的「更新于」按 UTC 显示，比北京时间早 8 小时 |
| 无 RSS / 站内通知 | 需要跟踪变更请用 `/api/v1/changes`（见 [api.md](api.md)） |
| 侧栏目录只列当前节 | 没有跨章的整书目录侧栏；跨章浏览走 Book 页的两级目录 |
